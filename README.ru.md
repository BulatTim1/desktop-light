# Desktop Light · Cursor Brightness

[English](README.md) · **Русский**

<img src="assets/icon.svg" width="64" height="64" alt="Значок Cursor Brightness — солнце">

Небольшое приложение для Windows: клавиши яркости управляют **монитором под
курсором**, а в быстрых настройках **Win+A** доступны отдельные ползунки всех
мониторов. Дополнительный ползунок находится в системном трее.

Desktop Light — репозиторий Windows-приложения **Cursor Brightness**.
**Один установщик содержит приложение и отдельную среду Windhawk для Win+A.**
Отдельно устанавливать Windhawk, .NET или драйвер дисплея не требуется.
Права администратора не нужны. Приложение не отправляет телеметрию. При первом
запуске или после обновления Windows модуль интеграции может загрузить
соответствующие отладочные символы Windows.

## Возможности

- Клавиши яркости управляют монитором под курсором; проверены **Lofree Flow Fn+F1/F2**.
- **SDR:** аппаратная яркость монитора через DDC/CI.
- **HDR:** яркость SDR-содержимого Windows без отключения HDR.
- Яркость встроенных экранов ноутбуков через WMI, если она доступна.
- Окно в трее с выбором монитора, ползунком, процентом и текущим способом управления.
- Ползунки всех мониторов в Win+A: видны две строки, остальные доступны прокруткой.
- Настраиваемый шаг клавиш: по умолчанию 5 процентных пунктов, повтор при удержании.
- Синхронизация со штатным всплывающим индикатором яркости Windows.
- Необязательный автозапуск, фоновая очередь записи с объединением запросов,
  обработка переподключения мониторов и выхода из сна.

Обычные F1/F2 и остальные мультимедийные клавиши не переназначаются. Клавиатура
должна отправлять стандартные события Consumer Control для яркости экрана.
Действия Fn, обрабатываемые только прошивкой и не передаваемые Windows,
приложение обнаружить не может.

## Загрузка и использование

Пакеты доступны на [странице релизов](https://github.com/BulatTim1/desktop-light/releases).
Артефакты успешных [сборок Windows](https://github.com/BulatTim1/desktop-light/actions/workflows/build.yml)
также можно скачать, войдя в GitHub:

- `CursorBrightness-<версия>-windows-x64-setup.exe` — установщик для текущего
  пользователя с ярлыком в меню «Пуск» и записью для удаления.
- `CursorBrightness-<версия>-windows-x64.zip` — переносимая версия. Распакуйте
  в постоянную папку и запустите `CursorBrightness.exe`.
- `CursorBrightness-<версия>-source.zip` — соответствующие исходники и файлы сборки.
- `SHA256SUMS.txt` — контрольные суммы пакетов релиза.

Требования: **Windows 11 24H2 или новее, x64**. В меню монитора должен быть включён
DDC/CI; кабель и док-станция должны его поддерживать. Некоторые режимы изображения
блокируют аппаратную яркость. Исполняемые файлы пока не подписаны.

Переместите курсор на нужный экран и нажмите клавишу уменьшения или увеличения
яркости. Нажмите значок солнца в трее, чтобы открыть окно приложения. При открытии
выбирается монитор под курсором; выбор сохраняется, пока вы меняете ползунок.
Другой монитор можно выбрать в списке. Щелчок правой кнопкой по значку или кнопка
**Options** открывают параметры клавиш, шага, обновления списка дисплеев,
**Start with Windows** и **Quit**.

Win+A, окно в трее и клавиши используют одну фоновую очередь записи. В Win+A
мониторы расположены слева направо по положению на рабочем столе. Видны две
строки; если мониторов больше, колесо мыши прокручивает список, в том числе над
ползунками. Перетаскивание ползунка меняет яркость соответствующего монитора.

Закрытие окна оставляет приложение в трее. При запуске приложение только читает
текущую яркость: сохранённые уровни, гамма-кривые и затемняющие наложения не
применяются. Настройки хранятся в `%LOCALAPPDATA%\CursorBrightness\settings.ini`.
В переносимой версии включайте автозапуск после выбора постоянной папки; после
перемещения включите его заново. Автозапуск использует задачу текущего пользователя
с задержкой 15 секунд после входа в Windows.

## HDR

Режим **SDR content brightness · HDR stays enabled** меняет уровень белого для
рабочего стола и SDR-содержимого. Он не меняет пиковую яркость HDR-панели или
настройки HDR-игры. При отключённом HDR используется аппаратная яркость DDC/CI,
если монитор её поддерживает. Шкала 0–100 соответствует 80–480 эталонным нитам.
Закрытый интерфейс Windows для записи уровня белого проверен на сборке 26100;
неподдерживаемый вызов завершается ошибкой без отключения HDR.

Штатный индикатор Windows может показывать аппаратную яркость, пока приложение
меняет яркость SDR-содержимого в HDR. Встроенный модуль синхронизирует отображаемое
значение существующего индикатора с процентом выбранного монитора. Сохраняются
штатные оформление, положение, время показа и индикатор громкости; собственный
индикатор не рисуется, штатный не скрывается. Данные приложения устаревают через
две секунды, после чего возвращается значение Windows. Если необходимые символы
не найдены, штатный индикатор работает без изменений. Шаг клавиш настраивается
независимо от собственного шага Windows.

## Интеграция с быстрыми настройками Windows

Полный установщик и переносимый пакет включают минимальную отдельную среду
**Windhawk 1.7.3** и скомпилированное расширение GPL. Она запускается вместе с
приложением, добавляет ползунки в **Win+A** и завершается по **Quit**.
Клавиши обрабатывает основное приложение; расширение передаёт ему изменения
ползунков. Среда внедряется только в `ShellHost.exe` для Win+A и `explorer.exe`
для штатного индикатора. При обновлении завершаются только приложение и его
вспомогательная среда; другие программы через Restart Manager не закрываются.

Интеграцию можно отключить через **Options → Windows Quick Settings (Win+A)**.
Если необходимые функции оболочки не найдены, быстрые настройки остаются
доступны, а окно в трее продолжает работать. Интеграция проверена на сборке Windows
26100; обновления Windows могут потребовать адаптации расширения.

Windhawk допускает одну работающую среду на сеанс. Если вы уже используете
Windhawk, завершите его для работы встроенной среды либо отключите встроенную
интеграцию и установите `mods/cursor-brightness.wh.cpp` в существующий Windhawk.
Во втором случае включите **standaloneBridge** и отключите **enableBrightnessKeys**
в параметрах мода. Для штатного индикатора также установите
`mods/cursor-brightness-native-popup.wh.cpp`. См. [руководство по расширению](docs/WINDHAWK.ru.md).
Другие установки Windhawk не перенастраиваются и не удаляются. Ошибки запуска
интеграции записываются в `%LOCALAPPDATA%\CursorBrightness\integration-error.txt`.

Для старой установки разработки сначала выполните
`tools/control.ps1 -Action DisableStartup`, затем `-Action Stop`, и только после
этого запускайте полное приложение. Удаление: **Параметры → Приложения →
Установленные приложения → Cursor Brightness → Удалить**. Для переносимой версии
снимите **Start with Windows**, выберите **Quit** и удалите распакованную папку.
Параметры в `%LOCALAPPDATA%\CursorBrightness` сохраняются; их можно удалить отдельно.

## Сборка

```powershell
git clone https://github.com/BulatTim1/desktop-light.git
cd desktop-light
```

Нужны Visual Studio 2022 или новее с компонентом **Разработка классических
приложений на C++**, Windows SDK и CMake:

```powershell
cmake -S . -B build/native -A x64
cmake --build build/native --config Release --parallel
ctest --test-dir build/native -C Release --output-on-failure
```

Результат: `build/native/Release/CursorBrightness.exe`. Библиотеки времени
выполнения линкуются статически. Для сборки сохранённых исходников основного
приложения Node.js и Windhawk не нужны. Для LLVM/MinGW используйте
`tools/build-standalone.ps1 -Compiler <путь-к-clang++.exe>`; подходит компилятор
из локального кеша.

Для полного дистрибутива установите Node.js и соберите интеграцию. Скрипт
загружает официальный подписанный установщик Windhawk в исключённый из Git кеш,
извлекает компилятор и подготавливает минимальную среду с чистыми настройками:

```powershell
.\tools\prepare-integration.ps1 -Destination build/native/Release/integration
.\tools\package.ps1 -BuildDirectory build/native/Release
```

С установленным [Inno Setup 6](https://jrsoftware.org/isinfo.php) выполните
`tools/build-installer.ps1 -BuildDirectory build/native/Release -Iscc <путь-к-ISCC.exe>`.
Либо сначала запустите `tools/setup-inno.ps1`: он подготовит официальный
подписанный компилятор в кеше; тогда `-Iscc` можно не указывать.
Соответствующие исходники Windhawk и лицензии включены в релиз.

## Диагностика и тесты

```powershell
Start-Process .\CursorBrightness.exe -ArgumentList '--diagnose "diagnostics.json"' -Wait
```

Команда только читает имена мониторов, способы управления и текущую яркость.
Она не меняет яркость и не записывает обычный ввод с клавиатуры. Автотесты
проверяют выбор и фиксацию монитора, отключения, нормализацию, HDR, границы,
повторные события, удержание и отпускание клавиш. Ручные сценарии приведены
в [списке проверок](tests/VALIDATION.ru.md).
