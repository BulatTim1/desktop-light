# Проверки и аппаратные сценарии

[English](VALIDATION.md) · **Русский**

## Проверено локально

Windows 11 26100.9457, x64; статическая сборка LLVM/MinGW. Удалённая сборка
CMake/MSVC в GitHub Actions также прошла компиляцию и тесты; результаты упаковки
смотрите в [запусках CI](https://github.com/BulatTim1/desktop-light/actions/workflows/build.yml).

- Общие тесты пройдены: отрицательные координаты и границы экранов, выбор
  по курсору, фиксация выбора панели, отложенное обнаружение, отключение без
  перенаправления, нормализация, пределы, HDR, дубликаты отчётов, отпускание
  и повтор удержания 400/100 мс. В Release проверки assert сохраняются.
- Основной EXE импортирует только системные DLL Windows.
- Отдельная среда Windhawk запустилась без интерфейса, компилятора и службы
  и загрузила расширение в ShellHost. Символы ControlCenter загружены успешно.
  Предыдущая отдельная установка была остановлена.
- Проверены открытие окна после фонового запуска, разметка и доступные элементы.
  Кнопка уменьшения изменила AOC Q27G2WG4 со 100% до 95%; независимое чтение DDC/CI
  подтвердило результат. Исходные 100% восстановлены.
- IPC Win+A изменил яркость на 5 пунктов; обратное чтение подтвердило результат.
  Значения вне диапазона и отключённые идентификаторы отклонены. Исходная яркость
  восстановлена. Эта проверка проверяет запись, а не взаимодействие с самой панелью.
- После принудительного завершения только тестового приложения повторный запуск
  принял уже работающую вспомогательную среду. Проверка IPC прошла с восстановлением
  исходной яркости.
- После завершения только вспомогательной среды приложение осталось работать
  и автоматически запустило замену при очередной проверке состояния.
- Свежераспакованный переносимый ZIP успешно выполнил команду диагностики только
  для чтения. Архивы включают скрытые файлы сборки и workflow, исключая журналы,
  кеши символов и состояние процессов.
- Установщик разместил оба компонента в тестовой папке без прав администратора.
  Создана интерактивная задача пользователя: задержка 15 секунд, без ограничения
  времени работы, три повтора при сбое. Запуск задачи запустил приложение
  и помощник; аппаратная проверка прошла.
- Удаление очистило тестовые приложение, помощник и задачу без оставшихся процессов.
  Реальный запуск после перезагрузки и входа остаётся ручной проверкой.
- Обновление поверх работающего приложения корректно завершило оба компонента,
  заменило файлы и сохранило задачу. Хеш установленного EXE совпал со сборкой.
  Старая задача автозапуска разработки удалена после успешной установки новой.

Ранние проверки мода подтвердили реальные HID-отчёты Lofree Flow Fn+F1/F2,
подписанный ползунок Win+A и выбор по курсору на AOC Q27G2WG4 и Titan Army G2785S.
HDR-механизм изменил яркость SDR-содержимого, подтвердил результат чтением
и сохранил HDR; пользователь подтвердил работу. В версии 1.1 пользователь проверил
основные функции и сообщил о несовпадении штатного индикатора Windows с процентом
яркости SDR в HDR.

## Версии 1.2 и 1.2.1

- Win+A показывает все подключённые мониторы в порядке рабочего стола. Высота
  ScrollViewer ограничена двумя строками, остальные доступны прокруткой. Привязки
  используют стабильные идентификаторы. Смена доступности и способа управления
  перестраивает список; обновление значения сохраняет позицию прокрутки.
  Пользователь подтвердил независимую работу обоих ползунков.
- Версия 1.2.1 сохраняет штатный индикатор Windows. Собственный индикатор и скрытие
  штатного удалены по запросу пользователя. Отдельный мод Explorer синхронизирует
  только модель отображаемой яркости с процентом монитора приложения. Аппаратные,
  звуковые настройки и политику питания он не меняет. Пользователь подтвердил
  совпадение штатного индикатора на обоих мониторах.
- Тесты канала индикатора прошли для отсутствующих отображений памяти, границ
  процентов, отключённых и недоступных целей, уничтожения отправителя. Общие тесты
  проверяют устаревшие и будущие метки времени. Обновления устаревают через две
  секунды после остановки публикации приложением.
- Общедоступные символы разрешили getter и setter штатного индикатора на этой
  сборке. Windows объединяет getter экрана и подсветки клавиатуры по одному адресу;
  проверка класса во время выполнения ограничивает обработку только экраном.
- Во время обновления были подключены G2785S в HDR с SDR white level 3500 — 50%,
  и Q27G2WG4 в SDR с аппаратными 100%. Запуск не изменил уровни и состояние HDR.
  ShellHost нашёл необходимые функции и оба монитора.
- Старая DLL движка, оставшаяся в Chrome, выявила конфликт Restart Manager.
  Установщик теперь завершает только свои компоненты, сохраняет уже установленные
  файлы в версионных папках движка и не закрывает посторонние программы.
  Фильтр среды допускает только ShellHost и Explorer; каждый мод работает
  в своём процессе. Обновление прошло при работающем Chrome.

Физическая проверка прокрутки с тремя мониторами ещё не записана. Ручной список
также включает перезагрузку, сон и перезапуск оболочки.

## Перед объявлением публичного релиза стабильным

1. Подключите оба дисплея. При закрытом Win+A наведите курсор на каждый:
   Fn+F1 уменьшает только его яркость на 5, Fn+F2 увеличивает. Проверьте быстрые
   нажатия, удержание, переход курсора между мониторами при удержании и пределы 0/100.
2. Откройте Win+A: каждый монитор имеет подписанный ползунок, видны две строки,
   остальные доступны прокруткой. Регулируйте независимо. Сверьте клавиши,
   Win+A и трей после обратного чтения.
3. В HDR проверьте подпись SDR brightness и изменение яркости рабочего стола
   без отключения HDR. После выключения HDR проверьте аппаратную яркость DDC/CI.
4. Сверьте полосу штатного индикатора с процентом Win+A: дополнительного
   индикатора быть не должно. Проверьте обычные F1/F2, громкость и воспроизведение,
   включая громкость сразу после яркости: штатный индикатор громкости доступен.
5. Переподключите монитор и измените расположение, включая отрицательные координаты.
   Недоступная цель не должна перенаправлять управление другому экрану.
6. После сна проверьте ввод и ползунки. При возможности перезапустите оболочку
   и убедитесь, что Win+A вернулся. Отключите и включите интеграцию: при отключении
   должна восстановиться штатная разметка.
7. Перезагрузите с включённым Start with Windows. После входа подождите 15–30 секунд
   и проверьте клавиши и Win+A, не запуская приложение вручную.
8. Проверьте обновление, выход и повторный запуск, отключение автозапуска и удаление.
   Настройки намеренно сохраняются.

Измерения яркомером не проводились. Док-станции, переходники, другие мониторы
и сборки Windows могут вести себя иначе. Перехваты оболочки и запись SDR white
используют закрытые интерфейсы; неподдерживаемые операции должны безопасно
завершаться ошибкой.

`tools/bridge-smoke.cpp` — явный аппаратный тест записи, исключённый из CTest.
Нужны `--exercise`, работающее приложение и доступный дисплей. При обычном успехе
или ошибке исходная яркость восстанавливается. Не прерывайте процесс посреди
записи. Диагностика должна оставаться в исключённой папке `build/`.
