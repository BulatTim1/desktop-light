# Участие в разработке

[English](CONTRIBUTING.md) · **Русский**

Соберите приложение по инструкции CMake в [README](README.ru.md) и запустите
CTest перед отправкой pull request. Опишите исходное и итоговое поведение,
сборку Windows и выполненные проверки.

Движок, использующий только Windows SDK, генерируется из адаптации Windhawk
с закреплённой исходной ревизией. Меняя движок, правьте `tools/customize.mjs`
или компоненты в `src/`, затем выполните:

```powershell
node tools/customize.mjs
node tools/generate-engine.mjs
node tools/generate-popup-mod.mjs
```

Не редактируйте сгенерированные движок и моды отдельно от их источников.
Для сборки сохранённых исходников основного приложения генерация через Node.js
не нужна. Код приложения находится в `app/`, общая логика клавиатуры, HDR и
выбора монитора — в `src/`. Модуль штатного индикатора генерируется из
`src/native-popup-mod.inc` и общих заголовков состояния индикатора и логики.

Проверяйте затронутые аппаратные сценарии: SDR/HDR, повтор клавиш, перемещение
курсора, переподключение, выход из сна, запуск и завершение. Не меняйте посторонние
настройки мониторов или яркость при запуске. Автоматические тесты записи должны
восстанавливать исходную яркость, кроме случаев, когда пользователь сам выбирает
новое значение.

Сохраняйте уведомления GPL и лицензии сторонних библиотек. Не добавляйте в Git
`build/`, `dist/`, `.cache/`, серийные номера устройств, личные пути, настройки
или локальную диагностику. При изменении документации обновляйте английскую
и русскую версии и ссылки переключения языка.
