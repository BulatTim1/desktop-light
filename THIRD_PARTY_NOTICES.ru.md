Основаны на **Per-monitor brightness and more in Quick Settings v3.0** автора
**bardelyne**, опубликованном в официальной коллекции модов Windhawk по GPL-3.0.

- [Исходник](https://github.com/ramensoftware/windhawk-mods/blob/b00b5e3043a606e9864405a111acaf29d69dc170/mods/per-monitor-brightness.wh.cpp).
- Исходная ревизия: `b00b5e3043a606e9864405a111acaf29d69dc170`.
- Неизменённая копия: `upstream/per-monitor-brightness.wh.cpp`.
- Изменения: выбор монитора по курсору, HID-клавиши яркости, управление
  SDR-содержимым в HDR, опрос только яркости, обратное чтение и обработка
  жизненного цикла и разметки.
- Исходное расширение отмечает использование кода взаимодействия с потоком XAML
  из Windows 11 Notification Center Styler автора m417z, также под GPL-3.0.

## Интерфейсы Windows

Синхронизация штатного индикатора использует общедоступные символы Microsoft для
отображаемого свойства `HWConfirmatorUI::BrightnessConfirmatorViewModel` в
`Windows.Internal.HardwareConfirmator.dll`. Бинарные файлы Windows не
распространяются; новый индикатор не создаётся. ModernFlyouts изучался на раннем
этапе исследования, но его реализация в этом релизе не используется.

Чтение уровня белого SDR использует документированный
`DISPLAYCONFIG_SDR_WHITE_LEVEL`. Закрытый ABI записи Windows сопоставлен
с [общедоступным примером](https://github.com/ledoge/set_maxtml/blob/master/main_sdrwhite.c).
Реализация написана для этого проекта и не копирует указанную программу.

Системные DLL предоставляются операционной системой и не входят в дистрибутив.

## Статически связанные библиотеки компилятора — MinGW/LLVM

LLVM libc++, libc++abi и libunwind используют Apache-2.0 WITH LLVM-exception;
компоненты MinGW-w64 — соответствующие разрешительные лицензии. Пакеты локальной
LLVM-сборки включают тексты лицензий библиотек времени выполнения. Сборки Visual
Studio используют статическую библиотеку Microsoft на условиях распространения
инструментария. Компилятор и SDK с приложением не поставляются.
