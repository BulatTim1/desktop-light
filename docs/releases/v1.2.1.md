# Cursor Brightness 1.2.1

**English** · [Русский](https://github.com/BulatTim1/desktop-light/blob/v1.2.1/docs/releases/v1.2.1.ru.md)

First public release of Desktop Light / Cursor Brightness for **Windows 11 24H2+
x64**.

## Features

- Brightness keys control the monitor under the cursor. Lofree Flow Fn+F1/F2
  is verified; default step is 5 percentage points, with held-key repetition.
- SDR monitors use hardware DDC/CI; HDR monitors use Windows SDR-content
  brightness while keeping HDR enabled. Built-in displays use WMI when available.
- Win+A lists every monitor with its own slider: two rows visible, scrolling
  for additional monitors. A tray window also provides monitor selection.
- The original Windows brightness popup follows the selected monitor's level.
  No custom brightness popup is displayed.
- One per-user installer bundles a private Windhawk runtime. Optional startup
  runs at normal user privileges, with no custom driver or .NET requirement.
- English and Russian documentation are included. The application UI remains
  in English.

## Compatibility and validation

Tested on Windows 11 build 26100.9457 with AOC Q27G2WG4, Titan Army G2785S and
Lofree Flow. The user confirmed independent Win+A sliders and the native popup's
matching brightness on both monitors. Core and shared-popup tests passed;
GitHub's MSVC build and tests also passed. Three-monitor scrolling, actual
reboot/logon, sleep/resume and shell-restart scenarios still need broader manual
validation. Laptop WMI support has not been validated on this desktop setup.

DDC/CI must be enabled and supported by the connection. A keyboard must send
Consumer Control screen-brightness reports. Shell hooks and the HDR setter use
private Windows interfaces and may need updates after Windows changes. Binaries
are unsigned. See the README and validation checklist for details.
