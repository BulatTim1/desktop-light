# Cursor Brightness 1.2.1

[English](v1.2.1.md) · **Русский**

Первый публичный релиз Desktop Light / Cursor Brightness для **Windows 11 24H2
и новее, x64**.

## Возможности

- Клавиши яркости управляют монитором под курсором. Проверены Lofree Flow Fn+F1/F2;
  шаг по умолчанию — 5 процентных пунктов, есть повтор при удержании.
- Для SDR используется аппаратная яркость DDC/CI, для HDR — яркость
  SDR-содержимого Windows без отключения HDR. Встроенные экраны используют WMI,
  если он доступен.
- Win+A показывает отдельный ползунок каждого монитора: две строки видны,
  остальные доступны прокруткой. В окне трея также есть выбор монитора.
- Штатный индикатор яркости Windows синхронизирован с выбранным монитором.
  Дополнительный собственный индикатор не показывается.
- Один установщик для пользователя включает отдельную среду Windhawk.
  Необязательный автозапуск работает с обычными правами; драйвер и .NET не нужны.
- Включена английская и русская документация. Интерфейс приложения остаётся
  на английском языке.

## Загрузка

- **Рекомендуется:** `CursorBrightness-1.2.1-windows-x64-setup.exe`.
- **Переносимая версия:** `CursorBrightness-1.2.1-windows-x64.zip`; распакуйте
  и запустите EXE.
- **Исходники:** `CursorBrightness-1.2.1-source.zip`, включая соответствующие
  исходники Windhawk и сведения о сторонних компонентах.
- **Контрольные суммы:** `SHA256SUMS.txt`.

## Совместимость и проверки

Проверено на Windows 11 26100.9457 с AOC Q27G2WG4, Titan Army G2785S и Lofree Flow.
Пользователь подтвердил независимую работу ползунков Win+A и совпадение штатного
индикатора с яркостью обоих мониторов. Тесты общей логики и канала индикатора
пройдены; сборка MSVC и тесты в GitHub также прошли. Прокрутка с тремя мониторами,
реальный автозапуск после перезагрузки, сон и перезапуск оболочки ещё требуют
расширенной ручной проверки. WMI ноутбуков на этом настольном компьютере не проверялся.

DDC/CI должен быть включён и поддерживаться подключением. Клавиатура должна
передавать Consumer Control-события яркости экрана. Перехваты оболочки и запись
HDR используют закрытые интерфейсы Windows и могут потребовать обновления после
изменений системы. Бинарные файлы не подписаны. Подробнее — в
[README](../../README.ru.md) и [списке проверок](../../tests/VALIDATION.ru.md).
