# Публикация на GitHub

[English](PUBLISHING.md) · **Русский**

Репозиторий проекта — [BulatTim1/desktop-light](https://github.com/BulatTim1/desktop-light).
Для новой рабочей копии клонируйте его. Для публикации изменений из существующей
копии проверьте diff, создайте коммит и отправьте его:

```powershell
git status --short
git add .
git commit -m "Describe the change"
git push -u origin main
```

Если вы скачали архив исходников без метаданных Git, сначала выполните
`git init -b main` и
`git remote add origin https://github.com/BulatTim1/desktop-light.git`.
Проверяйте индекс перед коммитом. `.gitignore` исключает кеши, результаты сборки
и журналы. Не перезаписывайте историю удалённого репозитория через force push.

GitHub Actions собирает приложение в Windows через Visual Studio/CMake,
запускает тесты, подготавливает отдельную среду Windhawk и расширения, создаёт
переносимый пакет, установщик и соответствующие исходники. Секреты репозитория
не нужны. Скрипты загружают официальные подписанные установщики Inno Setup
и Windhawk в исключённый из Git кеш; сами инструменты в репозиторий не входят.

После успешной сборки опубликуйте версию 1.2.1:

```powershell
git tag v1.2.1
git push origin v1.2.1
```

Сборка тега создаёт GitHub Release с пакетами. Текст описания берётся из
`docs/releases/v1.2.1.md`, если такой файл есть; иначе GitHub формирует его
автоматически. Русское описание хранится рядом в `v1.2.1.ru.md`; опубликованный
текст может включать оба языка. Для следующих версий обновляйте версию проекта
CMake, метаданные приложения, версию установщика по умолчанию и диагностическую
версию перед созданием тега. Опубликованные теги не перемещайте.

Сборки не подписаны, пока не настроен собственный сертификат подписи кода.
Ключи подписи и локальная диагностика не загружаются. Сохраняйте GPL-атрибуцию
Windhawk и соответствующий архив исходников. Не распространяйте кешированные
установщики инструментов, личные настройки, символы или журналы. Скрипт упаковки
использует только заново подготовленную минимальную среду и явный список исходников.

Проверяйте, что релиз содержит установщик, переносимый ZIP, архив исходников
и `SHA256SUMS.txt`. Английская и русская документация должны быть включены
в соответствующие пакеты.
