# Яркость по курсору в Windows 11

[English](WINDHAWK.md) · **Русский**

Это руководство описывает **отдельную установку для разработки или существующего
Windhawk**. Большинству пользователей подходит полный установщик из
[основного README](../README.ru.md): он включает отдельную среду и автоматически
управляет её запуском. Описанные ниже `.cache` и задача `control.ps1` предназначены
для разработки. Не включайте их автозапуск одновременно с полным приложением.

При использовании существующего Windhawk вместе с основным приложением задайте
`standaloneBridge=true` и `enableBrightnessKeys=false` в параметрах мода.
Основное приложение должно работать. Для старого варианта только с модом
оставьте `standaloneBridge=false` и включите клавиши яркости самого мода.

Полное приложение также загружает `mods/cursor-brightness-native-popup.wh.cpp`
в Explorer для синхронизации штатного индикатора яркости. Ему нужны общие данные
основного приложения; старая установка только с модом их не предоставляет.
Этот модуль меняет только отображаемое значение индикатора.

Проверено на **Windows 11 26100.9457**, клавиатуре **Lofree Flow — Fn+F1/F2**,
мониторах **AOC Q27G2WG4** и **Titan Army G2785S**.

- **Fn+F1** уменьшает, **Fn+F2** увеличивает яркость монитора под курсором.
  По умолчанию шаг — 5 процентных пунктов. Удержание начинает повтор через
  400 мс, затем повторяет каждые 100 мс. Обычные F1/F2 и прочие медиаклавиши
  не изменяются.
- **Win+A** показывает подписанные ползунки всех мониторов: две строки видны,
  остальные доступны вертикальной прокруткой. Строка сохраняет свой монитор
  при перетаскивании. Клавиши яркости по-прежнему следуют за курсором.
- **SDR:** аппаратная яркость через DDC/CI, VCP `0x10`.
- **HDR:** яркость SDR-содержимого Windows с подписью **SDR brightness**.
  HDR остаётся включённым; меняется уровень белого рабочего стола и SDR,
  а не пиковая яркость панели или внутренние настройки HDR-игр.
- Запуск и обнаружение мониторов только читают яркость. Гамма-кривые
  и затемняющие наложения не используются. Недоступный монитор не заменяется другим.

## Установка для разработки

Переносимая среда Windhawk находится в `.cache\windhawk` внутри проекта.
Драйвер и системная служба не устанавливаются. Сохраняйте путь проекта и эту
папку, пока включён автозапуск данного варианта.

Остановка и запуск из PowerShell в папке проекта:

```powershell
.\tools\control.ps1 -Action Stop
.\tools\control.ps1 -Action Start
```

Управление автозапуском:

```powershell
.\tools\control.ps1 -Action EnableStartup
.\tools\control.ps1 -Action DisableStartup
.\tools\control.ps1 -Action Status
```

Используется задача Планировщика **CursorBrightness** для интерактивного сеанса
текущего пользователя. Она ждёт 15 секунд после входа, явно задаёт рабочую папку
и повторяет неудачный запуск до трёх раз с интервалом в минуту. Задача работает
с обычными правами, в том числе от батареи, без пароля. Включение переносит старую
запись Run этого проекта в задачу. `DisableStartup` и `Uninstall` удаляют оба
варианта регистрации автозапуска этой установки.

`Stop` завершает эту переносимую среду Windhawk и выгружает её моды. Другие моды,
установленные позднее в ту же среду, тоже остановятся. Отключить только мод
**Cursor brightness in Quick Settings** можно на странице Installed Mods Windhawk.

Удаление настройки:

```powershell
.\tools\control.ps1 -Action Uninstall
```

Команда удаляет автозапуск, останавливает среду и отключает мод. Исходники
и переносимые файлы остаются для повторной сборки. Аппаратная яркость и уровень
SDR-содержимого сохраняют последние выбранные значения.

## Сборка и установка из исходников

Нужны Node.js и PowerShell. Скрипт загружает закреплённый официальный
офлайн-установщик Windhawk 1.7.3 и проверяет подпись издателя Authenticode.
Компилятор входит в среду разработки; Visual Studio для этого варианта не нужна.

```powershell
.\tools\setup-portable.ps1
.\tools\control.ps1 -Action Stop  # если среда уже работает
.\tools\build.ps1
.\tools\install-portable.ps1 -Start
```

Для другой **переносимой** папки Windhawk передайте `-WindhawkPath` этим скриптам.
Скрипт установки не создаёт автозапуск. Включайте его только после проверки панели
и клавиш на своей сборке Windows.

Исходник мода — `mods\cursor-brightness.wh.cpp`. Его можно установить через
**Create a new mod** в Windhawk: замените пример полным файлом, скомпилируйте
и включите. Отключите исходный per-monitor brightness, если он установлен,
чтобы два расширения не меняли одну панель.

Входные файлы сборки: `upstream\per-monitor-brightness.wh.cpp`, `upstream\REVISION`,
компоненты `src` и `tools\customize.mjs`. Генерация завершается ошибкой, если
ожидаемый фрагмент исходника отсутствует. Пересобирайте через `tools\build.ps1`;
сгенерированный исходник отдельно не редактируйте.

## Настройки и диагностика

Windhawk показывает **Enable hardware brightness keys**, **Brightness step**
и **Diagnose brightness keys without changing brightness**. По умолчанию клавиши
включены, шаг — 5, диагностика выключена. Изменение настроек перезагружает
расширение и сбрасывает состояние удерживаемых клавиш.

При остановленной среде `install-portable.ps1 -DiagnosticKeys -Start` устанавливает
диагностическую конфигурацию. Включите журнал мода Windhawk для просмотра нажатий
и отпусканий клавиш яркости. Ползунки продолжают менять яркость в этом режиме.
Consumer-отчёты разбираются по HID-дескриптору устройства; обычный ввод
с клавиатуры не регистрируется и не записывается.

Собранные программы диагностики:

```powershell
.\build\brightness-core-tests.exe
.\build\key-probe.exe 60          # только чтение: нажмите Fn+F1/F2
.\build\monitor-probe.exe         # только чтение DDC/CI и границ мониторов
.\build\hdr-probe.exe             # только чтение HDR и уровня белого SDR
.\build\hdr-probe.exe --exercise  # временный шаг 5; точное значение восстанавливается
```

`monitor-diagnostics.exe --exercise-primary` временно проверяет аппаратную яркость
основного монитора на 50% и восстанавливает её. Проверка показала, что G2785S
подтверждает DDC-запись, но игнорирует её при включённом HDR. `debug-log.exe 120`
собирает только отладочные сообщения Windhawk в течение 120 секунд. Запускайте
его перед Windhawk; не запускайте одновременно второй сборщик отладочного вывода.

## Совместимость и ограничения

Расширение Win+A работает в `ShellHost.exe` и проверяет необходимые символы
и структуру сетки перед добавлением элементов. Отсутствие функций оставляет
системную панель доступной. Обновление оболочки может потребовать новой проверки
совместимости. DDC/CI должен быть включён в меню монитора и поддерживаться кабелем
и док-станцией.

HDR определяется отдельно от режима широкого цветового охвата. Уровень белого
читается через документированный `DISPLAYCONFIG_SDR_WHITE_LEVEL`; запись использует
закрытую операцию Windows `0xFFFFFFEE`, проверенную на этой сборке. Шкала 0–100
соответствует 80–480 эталонным нитам. Неподдерживаемые вызовы сообщают об ошибке,
не отключают HDR и не перенаправляют управление другому дисплею.

Раздел «Параметры → Система → Дисплей» не изменяется. Переподключение, изменение
расположения и выход из сна запускают фоновое обнаружение. Идентификаторы
мониторов обновляются после переподключения; прежняя яркость не применяется
повторно при запуске.
